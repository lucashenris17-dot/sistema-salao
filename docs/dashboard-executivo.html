Fix: status_confirmacao

Bug corrigido no acompanhamento público
Problema

Causa

RPC fn_buscar_atendimento_publico não retorna o campo status_confirmacao.

✅

Solução Aplicada

Workaround implementado
1. Adicionado estado

2. Busca secundária via RLS
.eq('token_acesso', token)
3. Resolução de status
statusConfirmacao ?? status
4. Fix warning TypeScript
(payload) => (_payload)

Objetivo do Sistema

Sistema de gestão de salão de beleza para Inácia (profissional autônoma). Permite que clientes agendem horários online e acompanhem o atendimento em tempo real, enquanto a Inácia gerencia tudo pelo painel admin.

📅
Agendamento
Cliente escolhe data/hora online, Inácia aprova ou recusa
👥
Fila Presencial
Cliente entra presencialmente, ordem por chegada
🔴
Acompanhamento Real-time
Token único, status atualiza automaticamente
⚙️

Stack Tecnológica

Framework: Next.js 16.3.4
UI: React 19.2.8
Linguagem: TypeScript (strict)
Estilo: Tailwind CSS
Banco: Supabase (PostgreSQL)
Auth: Supabase Auth
Realtime: Supabase Realtime
